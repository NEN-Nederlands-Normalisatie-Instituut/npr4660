# Figuur 18 – Koppeling meetgegevens aan objecten

Dit diagram laat zien hoe meetresultaten (zoals oppervlakte of inhoud in m³) en geometrische vormen (via GeoSPARQL) worden gekoppeld aan ruimtelijke objecten. Het maakt gebruik van de SOSA-ontologie om observaties en resultaten (zoals een 'Tarra_meting') vast te leggen.
