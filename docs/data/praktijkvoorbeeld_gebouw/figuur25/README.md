# Figuur 25 – Totaal model gedecomponeerd gebouw

Dit is het sluitstuk van het hoofdstuk. Het biedt een totaaloverzicht van de decompositie van een gebouw, waarbij functies, ruimtelijke gebieden, technische objecten en de status van roerend/onroerend goed in één model zijn geïntegreerd. Het combineert bronnen uit BIM, basisregistraties en Geo-informatie.
