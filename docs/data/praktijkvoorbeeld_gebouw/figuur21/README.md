# Figuur 21 – Functioneel en technisch RuimtelijkGebied

Deze figuur illustreert het 'kwadrantenmodel' voor ruimtelijke gebieden. Het laat het onderscheid zien tussen waar een ruimte voor bedoeld is (de FunctioneleEntiteit, bijv. een operatiekamer) en hoe deze technisch is opgebouwd (de TechnischeEntiteit, bijv. de inpandige ruimte met muren).
