# Figuur 13 – Gebouw opgedeeld als RuimtelijkGebied en DiscreetObject

Deze figuur laat zien hoe een gebouw in de NEN 2660-systematiek gelijktijdig kan worden gemodelleerd als een verzameling ruimten (zoals een 'Inpandige ruimte' of 'Etageruimte') en als fysieke objecten ('Discreet gebouw'). Het toont de integratie tussen BIM-concepten (zoals IfcBuilding) en de Basisregistratie (zoals bag:Pand).
