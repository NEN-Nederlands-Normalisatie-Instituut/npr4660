# Figuur 17 – Netto- en bruto-inhoud als implementatie

Deze figuur visualiseert hoe verschillende bepalingsmethoden voor ruimte (volgens NEN 2580) worden gemodelleerd. Het toont dat een 'Vergaderzaal' als functionele entiteit verschillende implementaties kan hebben, zoals een 'Netto-inhoud' (gekoppeld aan IfcSpace) en een 'Bruto-inhoud' (gekoppeld aan IfcSpatialZone).
