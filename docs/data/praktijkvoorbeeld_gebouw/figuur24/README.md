# Figuur 24 – Fysiek gebouw gedecomponeerd

Figuur 24 toont de hiërarchische afbraak (decompositie) van een gebouw. Het laat zien hoe een gebouw wordt opgesplitst in inpandige ruimten, die op hun beurt weer worden onderverdeeld in specifieke functionele ruimten zoals een 'Hal', 'Trappenhuis' of 'Parkeergelegenheid'.
