# Figuur 23 – Onroerend goed en roerend goed als functionele entiteit van een TechnischeEntiteit en DiscreetObject

Dit diagram verduidelijkt hoe de NEN 2660-reeks omgaat met vaste delen van een gebouw (onroerend goed, zoals een wand of dak) versus losse objecten (roerend goed, zoals meubels). Het toont het gebruik van de 'heeftDeel'-relatie voor onroerend goed en de 'bevat'-relatie voor roerend goed.
