# NPR4660 repository

Deze repository hoort bij de [NPR4660][npr4660]. De NPR4660 geeft praktische handvatten voor de toepassing van de [NEN 2660-reeks][nen-2660-reeks] die de regels beschrijft voor het modelleren van fysieke en ruimtelijke objecten in de gebouwde omgeving.

Deze repository wordt voornamelijk gebruikt voor twee zaken:
* Het makkelijk leesbaar serveren van de figuren uit de NPR4660 via [deze website][pages], maar dan aangevuld met hun [RDF][rdf]-uitwerking in [Turtle][turtle].
* Het verzamelen en bespreken van [issues][issues] bij het toepassen van de [NEN 2660-reeks][nen-2660-reeks]

> [!NOTE]
> De website is op dit moment nog niet beschikbaar.

De voorbeelden sluiten aan bij de [Technische modelleerrichtlijnen voor linked data in de gebouwde omgeving][richtlijnen].

## Blijf op de hoogte van issues

Melding ontvangen bij elk nieuw of aangepast issue? Klik bovenaan de [repositorypagina][repo] op **Watch** en kies bij *Custom* de optie **Issues**. Je krijgt dan een notificatie (per e-mail en/of in je GitHub-notificaties) zodra er een issue wordt aangemaakt of bijgewerkt. Wil je slechts één specifiek issue volgen, abonneer je dan via de knop **Subscribe** rechtsboven op de pagina van dat issue.

## Development branch

Aanpassingen aan de repository doe je op de [development branch][development]. Alleen de NPR-commissie geeft wijzigingen uiteindelijk vrij via de [main branch][main]; wat op `main` staat, is leidend.
